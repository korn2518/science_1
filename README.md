# 과학 1 단원평가 기록보관소 (웹앱 v1.0.0)

중학교 1학년 과학 7개 단원의 단원평가 앱입니다. 단원마다 A형(개념 확인), B형(자료 해석), C형(생활 적용) 세 가지 유형이 있고, 유형마다 20문항(선택형 15, 서술형 5)입니다. 한 번 열어 두면 인터넷이 끊겨도 시험을 볼 수 있습니다.

## 폴더 구성

```
index.html              앱 본체 (문항 420개 포함)
manifest.webmanifest    앱 이름, 아이콘, 색상
sw.js                   오프라인 저장(서비스 워커)
fonts/                  고운바탕, IBM Plex Sans KR, 나눔손글씨 펜 (한글 2,350자 서브셋)
icons/                  앱 아이콘
.nojekyll               GitHub Pages 설정 파일 (지우지 마세요)
```

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다. 예: `science1-exam`
2. 압축을 푼 폴더 안의 파일을 모두 저장소 맨 위에 올립니다. `.nojekyll`은 숨김 파일이라 안 보일 수 있으니, 폴더째 끌어다 놓거나 GitHub Desktop으로 올려 주세요.
3. 저장소의 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/science1-exam/` 주소가 생깁니다. 이 주소를 학생에게 안내하거나 QR 코드로 만들어 나눠 주세요.

## 학생 기기에 설치하기

- **크롬북, 윈도우, 안드로이드 (크롬, 엣지):** 처음 열면 화면 아래에 "앱 설치" 버튼이 나옵니다. 주소창 오른쪽의 설치 아이콘을 눌러도 됩니다.
- **아이폰, 아이패드 (사파리):** 공유 버튼 → "홈 화면에 추가"를 누릅니다.
- 설치하지 않고 주소로만 열어도, 한 번 열어 둔 기기에서는 오프라인으로 동작합니다.

## 문항을 고친 뒤 다시 배포하기

1. `index.html`을 고쳐서 올립니다.
2. **`sw.js` 맨 위의 버전 숫자를 반드시 올립니다.** 예: `arc-science1-v1.0.0` → `arc-science1-v1.0.1`
3. 버전을 올리지 않으면 학생 기기에는 이전 문항이 계속 보입니다.
4. 새 버전이 올라가면 학생 화면 아래에 "새 버전이 준비되었습니다, 지금 적용" 안내가 나옵니다. 시험 중에 적용해도 답안과 남은 시간은 그대로 이어집니다.

## 알아 두실 점

- **응시 기록 위치:** 기록은 학생이 쓴 기기(브라우저)에만 저장됩니다. 공용 기기에서는 "열람증 바꾸기"로 학생을 바꾸면 학생별로 기록이 나뉩니다. 브라우저 기록을 지우면 응시 기록도 사라집니다.
- **서술형 채점:** 채점 기준의 핵심어로 자동 채점합니다. 결과지를 보고 선생님이 최종 확인해 주세요.
- **시간 초과 처리:** 시험 중 새로고침하거나 앱을 닫았다 열어도 남은 시간은 줄어든 상태로 이어지고, 시간이 지나 있으면 자동 제출됩니다.
- **글꼴:** 흔히 쓰는 한글 2,350자만 담았습니다. 그 밖의 드문 글자는 기기 기본 글꼴로 보입니다.
